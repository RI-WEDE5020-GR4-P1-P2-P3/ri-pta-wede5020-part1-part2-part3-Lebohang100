## WEDE5020 – Website Project

This project is a redesigned website prototype for Cotlands, a South African
non-profit organisation focused on increasing access to quality, play-based
early learning opportunities for young children.

The website was developed using:

- HTML5
- CSS3
- JavaScript

The website is responsive and designed for desktop, tablet and mobile devices.

---

# 1. Project Purpose

The purpose of the website redesign is to make information about Cotlands
easier to understand and navigate while making important actions such as
Donate, Get Involved, Volunteer and Contact easier to find.

The website is designed for:

- Parents and caregivers
- ECD practitioners
- Volunteers
- Donors
- Corporate partners
- Community organisations
- Members of the public

# 4. Main Features

## Responsive Navigation

The navigation works across desktop, tablet and mobile screen sizes.

On smaller screens the navigation changes into a mobile menu.

## Programme Information

The website contains information about:

- Early Learning
- Learning Resources
- ECD Training

## Impact Section

The website explains four areas of development:

- Cognitive
- Social and Emotional
- Physical
- School Readiness

## Get Involved

Visitors can select:

- Volunteer
- Partnership

The enquiry buttons open a JavaScript modal form.

## Donation Prototype

Visitors can select:

- R100
- R250
- R500
- R1 000

Visitors can also enter a custom amount.

The selected amount is displayed before continuing.

This is a prototype and does not process real payments.

## Resources

The resources page contains learning-resource information and a
searchable FAQ section.

## Contact Form

Visitors can submit a general enquiry using the contact form.

The current prototype displays a confirmation message.
